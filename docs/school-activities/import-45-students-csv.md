# 匯入 45 位學生 CSV

本教學說明如何在 **School Activities** 一次匯入 45 位學生。

!!! info "學生數量限制"
    School Activities 目前最多支援 **50 位學生**，因此匯入 45 位學生沒有問題。

## 1. 準備 CSV

建議使用以下三個欄位：

```csv
id,name,gender
1,學生01,M
2,學生02,F
3,學生03,M
```

### 欄位說明

| 欄位 | 是否必須 | 說明 |
| --- | --- | --- |
| `name` | **必須** | 學生姓名。亦可使用中文欄名 `姓名`。 |
| `id` | 選填 | 學號／排序編號。亦可使用 `學號`。沒有提供時，系統會按 CSV 行數自動編號。 |
| `gender` | 選填 | 建議使用 `M` / `F`，或 `男` / `女`。亦可使用中文欄名 `性別`。沒有提供時會顯示為 `Unknown`。 |

!!! warning "英文欄名請使用小寫"
    為確保目前版本可以正確讀取，英文欄名請直接使用 **`id,name,gender`**，不要使用 `ID`、`Name` 或 `Gender`。

### 45 位學生應有多少行？

第一行是欄名，因此：

- 第 1 行：`id,name,gender`
- 第 2–46 行：45 位學生
- 合共 46 行

可以直接下載本教學附帶的 [45 位學生 CSV 範例](examples/45-students-template.csv)，再把學生姓名及性別改成實際資料。

### 使用 Excel / Google Sheets

1. 在第一行填入 `id`、`name`、`gender`。
2. 在下面填入 45 位學生。
3. `id` 建議使用 1 至 45，避免排序混亂。
4. 儲存或下載為 **CSV**，並盡量使用 **UTF-8** 編碼，以確保中文姓名正常顯示。

## 2. 在 School Activities 開啟設定

1. 開啟 School Activities。
2. 按右上角的 **選單按鈕**。
3. 選擇 **「設定」**。
4. 找到 **「導入學生姓名」**。
5. 在 **「導入 CSV」** 一欄按 **「選擇 CSV 文件」**。

旁邊的 **「?」** 按鈕會顯示 QR Code，可開啟系統提供的 Google Sheets CSV 範本。

## 3. 選擇 CSV 檔案

1. 在裝置的檔案選擇器中找到剛才準備的 CSV。
2. 選擇該檔案。
3. 系統會讀取所有有姓名的資料列。
4. 匯入成功後會顯示：

> CSV 檔案匯入成功 🎉

5. 返回主畫面，確認共有 **45 張學生卡**。

## 4. 匯入後的排序

系統會按照 `id` 的數字大小排序。

例如：

```csv
id,name,gender
1,陳大文,M
2,李小明,M
3,張美玲,F
```

畫面上的次序會是 1 → 2 → 3。

因此建議 45 位學生使用連續的：

```text
1, 2, 3, ... 45
```

## 注意事項

!!! warning "匯入會更新目前學生清單"
    CSV 匯入後，系統會以 CSV 內容更新目前的學生清單。匯入前請確認正在使用正確的 Profile。

!!! tip "如已經分組"
    CSV 匯入只會更新學生清單，不會重設既有分組資料。建議先取消學生分組，再匯入新的班級名單。

- CSV 最多可包含 **50 位有姓名的學生**。
- 沒有姓名的資料列不會被加入。
- 如果沒有 `gender` 欄，學生圖示會使用未知性別的預設圖示。
- 若需要男女圖示，建議使用 `M` / `F` 或 `男` / `女`。

## 常見問題

### 顯示「Name column not found」

第一行沒有正確的姓名欄位。

請使用：

```csv
name
```

或：

```csv
姓名
```

如果使用完整格式，建議：

```csv
id,name,gender
```

### 匯入後不是 45 位學生

檢查以下項目：

1. CSV 是否真的有 45 個非空白的 `name`。
2. 是否有學生姓名留空。
3. 第一行是否只是欄名，而不是學生資料。
4. 是否選錯 CSV 檔案。

### 學生次序不正確

系統按照 `id` 數字排序。請確保 `id` 使用 1–45，而且沒有重複或非數字的值。

### 中文姓名顯示異常

重新將 CSV 儲存為 **UTF-8 CSV** 後再匯入。
